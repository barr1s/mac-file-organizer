# SortMe 

Sort me is a personal file organizer that automatically sorts my files into pre programmed directories 

The script runs every 60 seconds using launch agents, making it very light on resources 

# Have a Looksie 

If you want to use this script for yourself, look up how to program a plist to run python code

You will have to tweak the directory paths and names in the script because right now they are programmed for my system
